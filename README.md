# CodeAlpha_HangmanGame

A simple console-based Hangman Game developed using Python as part of my CodeAlpha internship.

## Description

This project is a word-guessing game where the player tries to find a randomly selected word by guessing one letter at a time.

The game selects a word from a predefined list of programming-related words. The player has a maximum of 6 incorrect guesses to find the complete word.

## Technologies Used

- Python

## Features

- Random word selection
- Programming-related words
- Displays the word with hidden letters
- Accepts one letter at a time
- Prevents repeated letter guesses
- Validates user input
- Allows up to 6 incorrect guesses
- Displays win or lose result

## Available Words

The game randomly selects from:

- Python
- Java
- JavaScript
- HTML
- CSS

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python HangmanGame.py
```
4.Enter one letter when prompted.
5.Continue guessing until you find the word or use all 6 attempts.

## Game Rules
- The program randomly selects one word.
- The player guesses one letter at a time.
- Correct guesses reveal the letter.
- Incorrect guesses reduce the remaining attempts.
- The player gets a maximum of 6 incorrect guesses.
- The player wins if all letters are guessed correctly.
